## Traps found this pass

- **A probe that matches itself**: the pointer-lock check searched the page for `requestPointerLock`, and the probe's own source
  contains it, so every game was flagged. Now it reads only scripts without `__gbPreview`.
- **`'\n'` inside the preview shim's template literal becomes a real newline** and breaks the injected script; there is now a
  `preview-shim-parses` case and sabotage.
- **A literal `</script>` inside the app script ends it** — check.py caught it; write `'<'+'/script>'`.
- **The browser pane being hidden pauses `requestAnimationFrame`** (and `getBoundingClientRect().width` reads 0 for headings).
  Don't conclude "game ignores input" or "no headings" from a hidden pane.
