## What changed
- **One design system** (`<style id="ds36">`): new dark and light palettes, system font stack (SF Pro / Inter / Segoe UI Variable),
  sentence-case headings, surfaces instead of outlines. Buttons now carry hierarchy with no markup change: plain `.btn` (the
  codebase already used it for Run/Send/Go) is the one solid button; `.btn.small` is tinted; `.btn.ghost` is neutral.
- **Navigation**: the 57-tab strip is gone by default. At ≥900px the same tab buttons form a grouped, foldable sidebar; below
  900px a five-item glass dock (Chat, Reason, Create, Brain, All) plus an "All" sheet with every tab as a grid. Tab position
  "auto" is the new default; anyone who chose top/left/right/bottom keeps it.
- **Header**: logo, one search field (⌘K — tabs, sections, settings AND content; the separate 🔎 search is merged in), model,
  key and local status, and ⋯ holding the rest (automate, project, fullscreen, pop-out, theme, tab mode, help).
- **Line icons** (Lucide 0.469, ISC) for every tab and group; emoji kept as an option (Customise → Tabs → "line icons").
  Leading emoji in headings/buttons are hidden in line style but stay in the DOM.
- **Less to read**: descriptions over ~260 characters fold to two lines with "More"; the suggestion bar shows one item.
- **Phone Assistant** behaves like a messages app: chat list and modes in single scrolling rows, composer above the dock.
- **Glass**: header, dock, menus, palette and toasts use a blur material that turns solid with Reduce Transparency.
  New opt-in effect **Living** (Customise → Effects): a quarter-resolution WebGL shader behind the glass, ~20 fps, paused when
  hidden or on 3D tabs, one still frame with reduced motion.
- **Free models**: LLM7 (no key, works in the browser, streams) and Kilo Gateway `:free` models (no key, through the bridge —
  Kilo sends no CORS header) both answered live. Free-key entries added: Hugging Face, NVIDIA NIM (bridge), SambaNova (bridge),
  Z.ai GLM Flash. Venice is listed as paid-uncensored. Help has "Free with no key at all" and "Free and uncensored".

## New features (from this month's open-source trends)
- **📐 Specs** (Build & ship): spec-driven development as GitHub Spec Kit does it — a constitution, then per feature a spec,
  a plan and small tasks, written by any model (works on the free no-key ones). Tasks carry dependencies like Beads: the
  **ready** list is computed (open + all deps done), cycles are flagged, and one ready task at a time is copied as a hand-off
  prompt or opened in the Assistant. Exports Markdown plus Beads-compatible `.issues.jsonl`. Stored in IndexedDB.
- **read_web_page tool**: agents read public pages as clean Markdown via Jina Reader (free, no key, answers browsers). It
  runs through `toolInvoke`, so the tool gate, injection scan and tracing apply; local/private addresses are refused.
  Toggle: ⌘K → "Web reader tool for agents".
- **Sabotage button no longer freezes the tab**: it ran ~240 suites in one synchronous task (10+ minutes); now sliced.
  It also no longer inserts a live `onerror=alert(1)` payload when escaping is sabotaged (that alert blocked headless runs).

## Measured, not shipped
- **Rust→WASM** byte scanner for REA (908 bytes, `dev/pass36/wasm/rea-scan`): on 64 MB, entropy 184 ms vs JS 186 ms, strings
  88 vs 208 ms. Under the 3× bar, and the JS version also finds UTF-16 strings. Kept as source only.
- **Go**: no part benefits without porting the whole bridge, which would mean two bridges to keep in sync.
- **Next.js / React rewrite**: not done. The app ships as one offline HTML file (PWA, desktop DMG, in-page gauntlet); a
  framework migration would break that and take months. The redesign uses current platform features instead.
- **Free uncensored hosted API**: none exists today (Venice bills free accounts; OpenRouter's Dolphin lost its `:free` route).

## Traps found this pass
- The tab-label code uses non-breaking spaces; anchors must match `\xa0`.
- `:not(#id)` carries id specificity — the phone header rule beat a later `#omnibtn` rule until doubled with `.s36.s36`.
- The old light theme forced `color:#fff` on every non-ghost `.btn` (specificity 0,5,0): tinted buttons went white-on-pale.
- Browser-pane screenshots go stale while the pane is hidden and its CSS animations pause; use headless Playwright
  (`dev/pass36/pw/shots.mjs`), and never animate content in from opacity 0.
