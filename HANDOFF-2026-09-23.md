## ⚠️ Pass 28 — read this before anything else

**Every model call in the app was broken from ~11 Sep until this pass.** `streamChat` used `label`
(`noteContext(label||model,…)`) without ever declaring it. Every call — local, direct provider and
OpenRouter alike — threw `ReferenceError: label is not defined` before leaving the page. Only Jev, UHP and
the Cua-S1 letter decider worked, because they use their own `fetch`. It is fixed, and it is now guarded
by a **call-path canary** (`callPathSmoke`). The canary runs 1.2 s after boot and sends `streamComplete`
through a local route with an already-aborted signal, so no request is made. A sound path ends in
AbortError; anything else puts a red "Model calls are broken" item in the health strip. It was checked
against the old build, where it reports exactly that ReferenceError. **If you touch the call path, check
`__gb.CALLPATH`.**

**Direct providers and the free no-key tier never worked either.** There were three stacked bugs:
- `streamChat` demanded the OpenRouter key on every route;
- `providerFor` skipped keyless providers, so OVH (shipped ON for first-run users) was sent to OpenRouter;
- OpenRouter-only body fields (`usage.include`, `reasoning`, web `plugins`) went to direct providers, and OVH rejected them with 400.

All three are fixed. The request to OVH now carries only standard fields; this was captured, not
assumed. A live OVH call returned 429 (its anonymous rate limit on this IP), so a real answer from the
free tier is still unproven.

**`withFallback` treats any answer under 120 characters as a failure.** Pass `shortOk:true` for
anything short by design, or every verdict, vote, sample, JSON plan and "391" buys a second paid call.
If the fallback itself fails, the original answer is now returned, and an unreachable fallback target is
skipped.

## Layout and the one hard rule

`GlassBox.html` is mirrored **byte-for-byte into four places** after every change:

```
gb-repo/GlassBox.html           gb-repo/index.html
glassbox-deploy/GlassBox.html   glassbox-deploy/index.html
```

Hash all five and expect one unique value. `check.py` sits beside the file and must print OK after
every edit. `window.__gb` is the only way to drive or inspect the app from outside, so anything you
want to test must be exported there.

## Verification workflow (required)

1. **Edit with assert-guarded string replacement** (`assert s.count(anchor)==1`). Build the whole
   edit in memory and write it once. An aborted edit script is **not** a no-op: grep for what it
   should have added.
2. Run `python3 check.py` after every edit. Before deploying, run `python3 check.py --stamp`.
3. **Verify live in a browser.** `.claude/launch.json` serves the folder on :8765 (config
   `glassbox`). Browser tools cannot open `file://`.
4. Run `gauntletRun()` and check that `r.green` is true. **The case array is `r.results`, not
   `r.cases`.** A probe that filters `r.cases` gets `[]` and reports "0 failed" while a case is red.
   This cost a whole round of measurement.
5. Run `gauntletSabotage()` **in its own page load, detached** (see traps). It must report
   `uncaught: []` and `restoredGreen: true`.
6. **A new test is not done when it passes.** Reintroduce the bug, watch it go red, then restore.
7. Sync all four copies and hash them. Commit with author `chriscarty123@gmail.com`, push, then run
   `vercel deploy --prod --yes --scope cloud-ops-game-time`. Curl the live URL and compare hashes.
8. Run `./gb-repo/desktop/build-desktop.sh`. It rebuilds the .app, DMG and zip and verifies them.
   Commit the result and copy the DMG to `~/Desktop/All Finished Apps/AI-Harness-0.2.0-macOS-arm64.dmg`.

`check.py` has 12 gates, each with a positive control. They match the **blanked** source (comments
and strings stripped) and skip the `GAUNTLET_SABOTAGE` span. Its duplicate-DOM-id gate is static,
so a ternary with the same `id="…"` in both branches fails it. That is correct: use one element.

## The three new tabs (newest, most likely to be built on)

Every design choice here traces to source that was read, not described. The spine's Pass 27 lists
the exact files.

### 🎯 System One (`view-systemone`, `s1Render`)

This is a port of **HarnessRouter/SystemOneHarness** (`actions.py gate.py controller.py encoder.py envs/`).

| function | what it is |
|---|---|
| `s1Space(decl)` | Validates a declaration. It refuses free-text params, reserved names and bad risk levels **at load**. |
| `s1Compile(space, candidates, disabled)` | Builds one questions map a step. It omits infeasible and disabled actions and records why. |
| `s1Judge(answers, compiled, space)` | The gate. It compares the **weakest** judgment (min, not product) with the bar for the action's risk: read 0.5, write 0.7, destructive 0.9. |
| `s1After(mem, verdict, goalP, gate, sig, streak)` | **Pure** termination rules: goal_reached, finish_insisted, no_confident_action, repeated_action, escalation_requested. `s1Run` calls it. |
| `s1Run(goal, {space, env, decide, …})` | The loop. `decide` can be injected and defaults to Jev with `exhaustive:true`. |
| `s1OrderDesk(scenario)` | Upstream's built-in environment. It needs no setup and has three scenarios plus a `goalMet()` check. |
| `s1CuEnv(backend, opts)` + `s1CuObserve` | System One on a real screen (webos / browserskill / cua). |
| `s1Go(opts)` | **The one runner all three tabs use.** |

There are three deliberate differences from upstream, each forced by this app's tested Jev client:
yes/no questions carry true/false criteria, questions go out exhaustive, and the cap is 254 options
rather than 255.

**Screen safety:**
- A click whose label reads as consequential (pay, send, book, delete…) becomes its own
  `click_consequential` action with **destructive** risk. It is omitted unless "allow clicks that
  commit" is ticked.
- Typed text never comes from the model. Values are supplied as `name = value` lines, and the value
  is never written to the trace.

### Computer-use additions (shared)

- **Cua Driver backend** (`CU_BACKENDS.cua`) runs `printf %s '<json>' | cua-driver call <tool>`, with
  JSON on stdin as in cua's `driver.py`.
  - It needs exactly one matching window (`cuaPickWindow`).
  - A click counts only if the driver reports `effect === 'confirmed'`.
  - Typing fails closed unless `list-tools` advertises `set_value`.
- **The Cua-S1 letter decider** (`s1LetterDecider`, `cuLetterPrompt/Parse/Answers`) copies the system
  prompt **verbatim** from `four_b.py`. It formats options as `A. role "label" -> action` and allows at
  most 26.
  - Logprobs are renormalised over the letters.
  - With no logprobs it takes a 5-sample vote, and the trace says so.
  - It can point at a local OpenAI-compatible server hosting Qwen/Qwen3.5-4B with the cua-s1 adapter,
    or at any OpenRouter model.
- **Why it exists:** Cua-Bench-S1 measured **Jev at or under chance on 5 of 6** held-out GUI
  families, while cua-s1-4b-0.2 scored 0.83–1.00. Jev decides *what*; a specialist can choose
  *which control*. The evidence table is on the System One tab. Leave `cua-s1-nano-0.1` out: it scored
  1.000 on its training split and 0.000 on every held-out one.

### 🔀 Harness Router (`view-router`, `hrRender`)

This is a UHP 2026-09-12 client, written from `protocol/versions/2026-09-12/*.md`.
- The default base is `http://localhost:3000/api/harness`. The **`/api/harness` prefix is required.**
- `uhpConnect` reads `GET /v1/uhp` first, which needs no key. A capability that is absent counts as
  false.
- `uhpRun`:
  - streams the answer and checks sequence numbers;
  - re-reads `GET /v1/responses/{id}` if the stream ends with no terminal event;
  - supports follow-ups via `previous_response_id`.
- **Stop sends `/cancel`.** Closing the stream does not stop a task on the server.
- `uhpHonesty` flags a model substitution the server **did not** report, and lists `ignored_fields`.
- `uhpBody` never sends `tools` or `include`. The spec reserves both.
- `uhpRoute` lets Jev pick the harness.
- Computer use for a *routed* harness is configured **on the harness**: `mcpServers` entries are remote
  only. A stdio server like `cua-driver mcp` must be packaged as a plugin. `uhpMcpEntry` builds the
  remote entry.
- The "through the local bridge" option uses the bridge's `/proxy` when the browser blocks a
  cross-origin call.

### 📊 Data Analysis (`view-analysis`, `daRender`)

Code counts, Jev chooses, and a model writes.
- `daParse` reads RFC4180 CSV, TSV, Markdown tables and JSON records.
- `daProfile` finds types, missing values, duplicates and IQR outliers.
- `daAggregate`, `daCorr` and `daTrend` compute the results. `daPlan` makes Jev choose over the
  columns that exist and falls back to `daDefaultPlan`.
- `daNarrate` writes from the computed facts only. `daNumbersCheck` highlights any number not in
  them. On its first probe it caught a figure I had invented myself.
- `daCaptureFromScreen` reads a table from BrowserSkill or a Cua window's `tree_markdown`.
  System One can navigate there first.

Tabs are wired in `TAB_GROUPS` (agents: systemone, router; know: analysis) and `ONB_INTERESTS`.
The Help tab has a card for all three.

## Invariants — breaking any of these is a regression

- **Nothing the user did not write runs on this origin.** Sandboxed iframes never get
  `allow-same-origin`, and that includes TREX frames.
- **A new tab must be added to `TAB_GROUPS`** (and to the tab bar and a section, which check.py enforces).
- **A gauntlet case must call through the same `g.` export its sabotage replaces.** Module-scope
  calls are unaffected by sabotage, and this trap has now bitten three times.
- **`gauntletRun` is strictly synchronous.** An async `run:` goes red, or worse, passes vacuously.
  Put loop logic in a pure function (as `s1After` and `reactDecide` do) and test that.
- **`'use strict'` throughout:** no `arguments.callee`. Use a named function expression.
- **Reassigned top-level `let`s exported on `__gb` need `get`/`set`.**
- **`IDB.set` returns false, it does not throw.**
- **Only approved Beacon memories reach a prompt.** Imported logs are data, never instructions.
- **Model outputs never supply typed values on a screen, and never compute reported numbers.**

## Traps that will waste your time

- **`gauntletSabotage()` now takes ~60 s** (99 sabotages × 225 cases). The browser tool gives up at
  45 s and reports "Internal error". The previous build takes 48 s, so this is scale, not a hang. Run
  it detached:
  `setTimeout(()=>{window.__sab=window.__gb.gauntletSabotage()},50)`, then read `window.__sab` later.
- **Run `gauntletRun` and `gauntletSabotage` in separate page loads.** Together, the brain-rank cases
  go red and `restoredGreen` reads false.
- **Test on a clean origin.** Each of `127.0.0.1:8765`, `localhost:8765` and `[::1]:8765` has its own
  storage, and another port gives two more. On an origin you have already tested on,
  `bots-audit-records`, `dossier-derived` and `section-order-is-one-authority` can go red from leftover
  state. On 23 Sep a sabotage run left `gb.tabmode='full'`. **Reproduce on an untouched origin before
  calling anything a regression.** On clean origins, both the previous build (87/87) and this one
  (99/99) restore cleanly.
- `go()` takes the `data-view` value (`systemone`), not the section id.
- The browser pane is usually hidden, so `requestAnimationFrame` never fires and layout measures 0×0.
- The onboarding modal appears on a fresh origin. Click "Skip, show me everything" before screenshots.
- `vercel deploy` needs `--scope cloud-ops-game-time`. A wrong git author email shows up as a false
  "upgrade to Pro" prompt. **Chris is on the free plan and does not want to upgrade.**
- iCloud Drive: `git` can report `index.lock … Operation timed out` **while the commit succeeded**.
  Compare `git rev-parse HEAD` with `origin/main` before re-committing.
- **Don't live-test local models over 9B on this Mac. It crashes.** Cua-S1 4B is within the rule but
  has not been run here.
- `indexedDB.deleteDatabase()` from a live page wedges IDB for the whole origin. Use a new origin instead.
