## Pass 34 · every model picker sees the whole, current catalogue

The problem, measured: OpenRouter has **686** models when asked for every output modality, **468** by default. The app asked the
default question, never re-asked once a copy was cached, and then cut what it had: 11 lists at 300/400, the model menu at 150, the
Catalog table at 400.

- `catalogFetchRemote` asks `/models?output_modalities=all` (664 after dropping 22 `~` aliases), falling back to the plain call.
- `catalogRefresh()` refreshes **every source at once** — OpenRouter, each keyed provider, Ollama, the other local runtimes, the bridge —
  single-flight (`CAT_BUSY`), each failure isolated, results in `CATALOG_META.sources` (`catalogSummary` words them).
- Boot refreshes a cache older than 30 min (`catalogStale`); opening any model menu on a stale list refreshes it too. A refresh that
  ran in the last 2 min is not retried (offline machines do not refetch on every click).
- `modelKind` (chat / image / video / speech / embed / other, from `architecture.output_modalities`). Chat pickers show chat models by
  default (462); one select shows the rest.
- `modelOptionsHTML` / `modelDatalistHTML`: the whole list, grouped by provider, current value kept even when unlisted, last option
  "🔍 Search all N models, refresh the list…". Lists rendered with `modelListAttrs()` (`data-models`) **repaint themselves** when the
  catalogue changes (`modelListsRepaint`, called from `mergeCatalog`; skips the focused element).
- `modelSelectWire` (boot): choosing "🔍 Search all…" in any native model select opens the searchable menu and writes the pick back.
- The menu (`modelMenu`): count + age, ↻ Refresh, kind and provider selects, no cap, header pinned while the list scrolls, flips/pins
  itself to stay on screen.
- Models tab (MoA): full grouped lists, ↻ refreshes all sources, status line. **Bug fixed:** the ▾ beside a member wrote into the hidden
  custom box, so the visible dropdown never changed and the pick was lost on save.
- Catalog tab: kind filter, per-source status, all rows, a **Use** button (sets the app-wide primary model).
- `genImageModalities`: image-only models (Flux, Seedream…) are asked for `['image']`; the image picker grew from ~12 to 61. Video:
  OpenRouter's 30 video models are browsable in Catalog but kept out of the video generator, which has no OpenRouter route — they
  would have displaced the working Gemini/Replicate entries.
- **Deliberately not done:** syncing no-key providers. Pollinations' `/models` lists 563 models anonymously and answers for 3; listing
  them as "FREE · no key" is a menu of failures. A provider's full list appears once its key is in.
- `MODEL_FIELD_RX` now also covers `-judge` and `-lmod` (Prompt Evolution's judge, System One's model had no ▾).
