## What is new

- **☁️ Cloud terminal** (Terminal tab card, `p35-cloud`): a bridge that runs in the cloud, used from any device, this phone included.
  `glassbox-bridge.mjs --remote` (or `GLASSBOX_REMOTE=1`) binds 0.0.0.0, requires a token on every endpoint except a minimal
  `/whoami`, refuses `/pair`, and `--tunnel` starts a cloudflared quick tunnel. `.devcontainer/` + `cloud/Dockerfile` give a
  Codespace with Claude Code, Codex, OpenCode, Gemini CLI, Oh My Pi, REA and Playwright preinstalled. Use: auto (local first, cloud
  when no local bridge), always, off. `bridgeBase()` replaced every hard-coded bridge URL.
- **🛠 Fix these** on any failing gauntlet case: case code + source of its `uses` + got/expected → a model classifies it (app bug /
  test assumption / environment) with a patch; or hand it to a coding harness through the bridge, gated by `check.py` and
  `tools/run-gauntlet.mjs` (desktop + `--mobile`). A harness that claims a fix it did not make is not marked green (verified).
- **♻️ Harness²** — port of google-research/harness2 (Apache-2.0): Propose → Probe → Compose, INV/DOM editors, parallel or sequential
  k, blind anonymised selection, experience reflection into a per-domain library. Executors: an in-app model or a coding harness via
  the bridge. Offline scripted demo.
- **🔬 REA** — attach files; in-browser parsers (PE, ELF, Mach-O/fat, WASM, ZIP/APK/JAR, ASAR, GGUF, safetensors, SQLite, HAR without
  header values, JS) produce evidence items; model or swarm (≤5) builds a CONFIRMED/HYPOTHESIS ledger (uncited claims demoted), a
  behaviour spec, a clean-room rebuild into Studio/Artifacts. Through the bridge: real `rea-agents` CLI (correct command per file
  kind), Ghidra via bethington/ghidra-mcp HTTP — **only read-only tools are offered to the model**.
- **Intelligent UI**: per-turn route (text/table/chart/diagram/tool/map/3D) with a chip saying why; Mermaid component + ```mermaid
  fences (mermaid 11.4.1, `securityLevel:'strict'`, loaded on first diagram); GenUI compare (two models side by side).
- **Plain English (ASD-STE100, 80%)**: output style, `steLint` (port of danyuchn/asd-ste100-skill structural rules), and an
  "Explain as" row: STE, diagram, interactive page, narrated explainer (browser speech synthesis).
- **Frameworks**: LangGraph, Mastra, Agno, Cognee, Graphiti, Browser Use, E2B (Web Worker + Pyodide 0.26.4 sandbox), Langfuse,

## 35c — the self-test was changing people's data

Found on the iPhone: the gauntlet's fork test left three real chats ("fixture", "fixture — fork @1/2") per run, and at the 60-chat
cap that pushed out the three **oldest real chats**. Diffing every `__gb` getter and every `gb.*` key across one run found eleven
more stores it wrote to (Creations "gauntlet probe", WebOS windows, activity log, Society turns, activations, a breaker, the
persist-failure counter, …).

- `gauntletRun()` is now `gauntletSandbox()` + `gauntletRunCases()`: snapshot of the touched app state (`GAUNTLET_SANDBOX_STATE`) and
  of every `gb.*` key, restored in `finally`. Verified: after a run the only changed key is `gb.gauntletLast`.
- Boot sweeps remove what earlier runs left: `fixtureChatSweep` and `gauntletResidueSweep`, each matching one case's exact fixture
  (bot names BellA…OneB, title "gauntlet probe", task "task", …) so nothing a person wrote can match. Cases + sabotages for all three.
