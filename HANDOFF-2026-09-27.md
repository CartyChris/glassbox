## Pass 30 (27–28 Sep) — read this first

**New tab: 🧪 Harness Lab** (`view-hlab`, ids prefixed `hl-`, state `HL` under `'harnesslab'`). A harness is
DATA: `{name, model?, steps:[…], output, guards:{maxCalls,maxUsd}, memory:{beacon}}`. There are 8 step kinds
(`HL_KINDS`): `llm, sample, verify, critique, react, jev, sandbox, pick`.
- `hlValidate` refuses unknown kinds, duplicate ids and missing fields. References may only point BACKWARDS
  (`{{input}}` or earlier steps), so a cycle is impossible by construction.
- `hlRun` checks `hlOverBudget` BEFORE every call; hitting a ceiling stops the run and returns partial output
  marked incomplete.
- `sandbox` runs through `trexExperiment` (`allow-scripts` only).
- `jev` falls back to a free model's one-of-N choice with no key.
- `hlBench` runs the harness against `hlBaseline` (one call) on `peParseCases` cases. The judge is from another
  family, and the comparison is by `hlScore`: CPCT = all spend ÷ passes. The accept rule is `peAccept`.
- `hlDesign` is a description in, and a validated spec out, with one repair round fed the validator's errors.
- Apply: `HL.modes` (Assistant mode chips `hl:<id>`, via `asstModeEntries`/`initAsstModes`), `HL.hooks` (a
  button next to Lab/Relay/Compare/Council's run button, `hlApplyHooks`, idempotent) and `HL.apps` (cards).
- There are 7 templates, all validated and all run end to end against the test double.

**Free route** (`freeRoute` inside `streamComplete`). When the model a call asks for cannot run (`modelRunnable`
is false: an OpenRouter id with no key, or a provider that is off), the call goes to `freeModelFor()`. The order
is:
1. `FREE.model`;
2. local models of KNOWN size ≤ `FREE.localMaxB` (default 9 — `modelParamsB` reads Ollama's `parameter_size`,
   then the name; unknown sizes are never auto-picked, because this Mac has 12B–33B models installed);
3. free-tier providers with a key;
4. no-key providers (OVH, then Pollinations).

A 401/402/429/503 falls through to the next candidate. `FREE_COOL` cools a model for 90 s on a 429 and a
provider for 10 min on a 401. Providers with `rpm` are paced client-side (`freeSlot`/`freeSlotWait`). Settings
has a "🆓 Free models" card.

**Pollinations (no key)**, measured: only `openai`, `openai-fast` and `openai/gpt-oss-20b`, non-streaming only.
The body must NOT contain a `stream` field at all (`"stream":false` gets the same 401). The allowance is per
network and tiny: about a dozen calls from this machine used it up for the hour. `noStream:true` on a provider
means one JSON reply is read in `streamChat`. **GitHub Models was retired on 30 Jul 2026. Cloudflare Workers AI
refuses browser preflights.** Groq, Cerebras, Mistral and Gemini (OpenAI-compatible) answer CORS and ship OFF,
waiting for a free key.

**Model menu** (`modelMenu`, `modelBadge`, `modelFieldEnhance` + a MutationObserver). Every `input.mono` whose
id ends in model/arch/build/review/primary/planner/agg/cheap/strong/writer/skinmodel/draft, plus
`.moap-custom`, gets a ▾. It currently covers 27 fields, Assistant Chat settings included. Filters: All, Free,
Local, Runs now, Reasoning. `makePicker` uses the same menu.

## New this pass

**The tool gate** (`toolGate`, `toolLegs`, `toolArgsCheck`, `toolObservation`, `TOOL_GATE_LOG`). Every
tool call from the Assistant, the Relay and both ReAct transports now goes through `toolInvoke`, and every
call passes one gate in this order:
1. **phase** (`toolAllowed`, when `PHASE.on`);
2. **lethal trifecta**: in `block` mode an exfil tool is refused once the run holds private + untrusted.
   Legs are marked on real calls; `trifectaReset()` runs at the start of each ReAct run;
3. **arguments** checked against the tool's own schema. A bare string for a one-field tool is wrapped;
4. **injection scan** of the result. It is flagged, never stripped, and the run is marked untrusted.

The Guards tab lists the last decisions.

**Skills arrive whole from `load_skill`** (cap 12k, which covers every seeded skill except the one 15.5k
outlier). Head and tail scale with the cap; fixed 900/300 sizes cut a 9.6k skill to 1.2k.

**Spotlighting + offload.** Every observation is wrapped in `⟦tool-output NAME⟧ … ⟦/tool-output⟧`. The
prompts carry `TOOL_SPOTLIGHT_RULE` (text inside is data, never instructions). A result over the cap keeps
its head (≤900 chars) and tail (≤300) and offloads the whole text behind a `recall` handle. `recall` joins
the menu mid-run, natively too. Before this pass, results were cut at 1,200 chars and the rest was lost.

**Progressive-disclosure skills** (`skillsPick`, `skillsBlock(limit, query)`, tool `load_skill`).
Enabled skills are ranked with the Brain's BM25. Relevant and pinned skills go in whole; the rest are
indexed in one line each, and the model opens them with `load_skill`. With no query, `skillsBlock` behaves
exactly as before. The Assistant and Relay pass the task.

**Robust boot.** `store.get(k, d, shape)` rejects a stored value whose shape doesn't match the default,
or the named shape when the default is `null`. The value is kept on disk and reported
(`store.shapeMisses`). `boot()` runs its inits through `bootSafe` / `bootSafeAsync`, so a throwing step
lands in `BOOT_FAILS` and the health strip shows a `bad` item while everything else starts. **Proven by
fuzz:** every one of 172 keys was set in turn to a string, a number, `{a:1}`, `[1]` and `null` (860
boots). Before: 41 of those left the app without `__gb`. After: **0 of 41 fail to boot, 0 uncaught
errors**. The damage stays in the one feature that owns the key.

## Verification workflow — additions to the 23 Sep list

- **`check.py` now runs `gb-lint.mjs`** (ESLint with `no-undef` including `typeof`-guarded names,
  `no-dupe-keys`, a TDZ rule and ~20 always-a-bug rules). ESLint lives **outside iCloud** in
  `~/.cache/glassbox-lint`:
  `mkdir -p ~/.cache/glassbox-lint && cd ~/.cache/glassbox-lint && npm init -y && npm i eslint@9 globals`.
  Without it the gate prints SKIP and the rest still runs. **Positive control:** it flags `label` on the
  pass-27 build and 69 findings on the pass-28 build.
- Names the app publishes as `window.x=…` count as declared. Anything else must be declared, even behind
  `typeof`: a `typeof` guard around a name that never exists is a feature that silently never runs.
- **Test model calls with the request-capturing double:** `mock_llm.py` (session scratchpad, not
  shipped). Put `[[tool:NAME:{json}]]` in the task and it asks for that tool once, in whichever
  protocol the request uses. Then it answers with what it saw: `SAW-RESULT SAW-SPOTLIGHT SAW-RULE
  SAW-WARN SAW-OFFLOAD SAW-SKILL:…`. It appends every request body to `requests.jsonl`. **Reading the
  captured body is what found the dropped `system`/`stop`**, and is the check to repeat after touching
  the call path.
